# 第七步：筛选与数据效用实验（2026-09-14）

本次继续原项目，不重新建项目。两个问题分开检验：执行反馈能否支持可靠筛选，以及现有合成动作在固定计算预算下是否改善跟踪。

## 先检查物理标签是否成立

已有 48 条配对仿真由同一个冻结控制器执行，全部提前失配；20 条接触优化配对也未完整执行。接触未被观察到不能自动标成接触失败，提前失配也不等于跌倒。全身碰撞审计尚不完整。

因此完整的 Physics Critic（物理评价网络，预测跟踪、跌倒、接触和碰撞）仍要求可靠标签，入口拒绝未批准记录。本次额外训练一个范围更窄的 Controller Coverage Critic（控制器覆盖预测器）：只预测给定固定控制器的首次跟踪失败时间，不能判断动作本身是否物理可行。

覆盖预测实验使用已有 48 条真实双机器人执行记录，重复环境合并成一条动作记录；以四种文本条件为组，前两组训练、第三组验证、第四组回顾性测试。相同提示的噪声变体和两种生成版本不跨集合。只输入参考关节轨迹和其导数，不输入实际执行误差。三个预测器种子，150轮，验证误差选模型；对照训练均值常量预测。保留测试组每种生成版本 K=6 的候选排序结果。

这些历史记录已经查看过，故为回顾性诊断。即便预测误差较小，也必须同时有完整执行成功的校准样本和完备接触/碰撞观测，才允许用于筛选可执行数据。本次不放宽这一门槛。

## 同预算数据效用实验

|组别|训练数据|实际含义|
|---|---|---|
|A / real|20条 KungFuAthlete 来源动作|视频重建再重定向，非光学 MoCap|
|B / generic|A＋20条普通生成防守动作|TIMotion 固定完整攻击者动作后的生成|
|C / contact|A＋20条接触约束生成防守动作|相同条件和随机噪声，增加已训练动作适配器及保持骨长的接触优化|

新增生成条件只选训练集前20个不同来源；不复用先前20个测试来源的生成动作。B、C 使用相同人体→G1 位置逆运动学和参考转换。第三组尚未经过可靠物理筛选，不能称“物理验证通过的数据”，也不是完整方法最终实验。B与C比较的是适配器＋接触优化组合，尚不能分离接触模块独立贡献。

所有组使用同一 PPO、同一网络、原有奖励，512环境×24步×1000次更新，即每次12,288,000环境步；从随机初始化训练，种子0/1/2。最终模型用于测试，不根据测试结果选择训练轮数。A的种子0复用同数据校验值、同配置和预算的既有模型，其余8次新训练。每片段均匀抽样，因此B/C预期50%来源动作、50%生成动作；这是固定总预算的数据策略比较，非固定真实数据曝光量比较。

共同评价4个保留来源片段，每片段32个环境、重置种子123。它们全部来自同一个独立视频标题组，且此前已看过基线结果，因此只是开发留出集，不能作为未触碰的最终测试集或4个独立视频。每个种子的四片段平均作为一个统计值；报告3个控制器种子的均值、样本标准差和配对差值。生成模型和生成数据只建立一次，不声称生成器三种子重复。

主指标：完成全段且平均身体/根部位置误差分别低于0.15米、关节误差低于0.3弧度的比例。次指标：全段未失配比例、首次失配时间、关节和根部误差。误差只在首次失配前统计，必须配合时长解释。阈值沿用原项目诊断，不是官方标准。

单机器人效用实验不检验双方对抗、接触力或战术收益。完整第七步是否通过，必须结合以上范围；负结果照实记录。
