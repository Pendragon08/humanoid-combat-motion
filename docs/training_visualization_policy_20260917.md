# 后续训练启用图形界面并在本地查看

## 用户决定与适用范围

2026-09-17：本次正在运行的RL训练保持原样，不中断、不重启；后续新启动的仿真RL训练启用图形界面，允许从本地电脑查看服务器训练中的机器人动作。

此文件是后续启动要求，不代表服务器图形服务已经配置完成。本次只记录要求，没有连接或更改运行中的训练进程。

## 后续启动前需要完成

1. 检查服务器可用的桌面／远程图形会话与GPU渲染能力。复用已配置服务；如需新增，按服务器实际环境选择方案，不预设某种远程桌面已安装。
2. 建立本地电脑到该图形会话的连接，并实际确认本地能看到服务器窗口。入口仅限用户授权的连接，不公开暴露图形服务。
3. 在新实验配置中启用仿真器Viewer（图形观察窗口）。IsaacGym/PBHC若沿用当前接口，应在新配置的最终生效参数中设置`headless=False`；其他仿真器使用相应配置。
4. 以小规模预检查确认：窗口可见、画面更新、GPU正常、关闭本地查看连接不会终止服务器训练。可显示少量代表环境，训练环境总数、奖励、算法与科学对照预算不因展示需要擅自调整。
5. 记录本地查看入口、连接步骤、实际生效配置与渲染频率。图形渲染可能占用GPU资源，启动前检查速度和显存余量。

图形预检查失败时先报告具体问题并修复；未经用户同意，不自动启动无界面正式训练。

## 当前正式训练保持不变

当前 `configs/pbhc_official_reproduction_v1.json` 中的`headless=True`属于已冻结实验配置。启动器会核对输入文件哈希；不得为兑现“以后启用图形界面”而修改本次运行的配置、启动脚本或依赖，也不向当前训练发送重启／中断命令。

后续采用新的配置版本与实验目录。当前训练若由其既定脚本接续评价，也不因本要求改动正在执行的冻结队列。

## 查看内容要标清楚

- 训练中的Viewer：当前策略在训练仿真里的表现，是用户要求的默认查看方式。
- 独立评估窗口：加载某个已保存检查点进行测试，须注明检查点和测试设置，不能称为当前训练直播。
- 视频回放：某一时段录制结果，不能称为实时画面。
- 训练曲线：奖励、误差和步数等指标，可作为补充，不能代替机器人图形画面。
