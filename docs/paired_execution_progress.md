## 实际发现和修正

1. G1退出挂起来自 Isaac Lab 时间线停止回调的暂停渲染循环。关闭应用前调用 clear_instance() 解除回调，独立复核通过。
2. TIMotion 原始输出出现跨帧人物编号互换，不能直接变成机器人轨迹。新增最小连续性代价的人物对应后处理；只交换编号，不改变每帧几何，不推断攻击/防御角色。保留原始结果与校正后结果，不能把后处理效果归为新的动力学生成方法。
3. 固定起点评估首次 reset 后参考位置缓存为零，导致假失败。两份旧评估保留但作废；现在在不推进仿真或参考时间的前提下初始化缓存。
4. 修正后的100轮策略仍未完成该参考动作：32环境完成比例0，首次跟踪失败在第3–5步。这里只能说明短程策略不够，不能证明生成课题不可行。已继续训练并将重新评估。
