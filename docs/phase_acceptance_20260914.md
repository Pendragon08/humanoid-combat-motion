## 已经获得的有用发现

1. **接触指标可能被钻空子。** 软位置优化使骨段最多改变20.36厘米。把骨长写进生成参数化并将优化目标设在评价容差以内，可以避免这种错误；这仍不是完整机器人约束。
2. **接触在重定向中丢失。** 能明确映射的11例中只有4例保留近似接触；另9例因人体与机器人部位映射未确定而不计分。不同分母不能直接相减比较。
3. **存活、姿态、空间关系必须分别评价。** 同一参考的最终控制器30/32维持全段，身体相对误差约8.1厘米，世界坐标身体误差约43.9厘米。本课题的空间筛查仍0通过。
4. **双机器人接口需要阳性对照。** 两台相隔3米执行已学种子参考，4/4维持全段、无对方接触。这是人为构造的非格斗控制，不是配对真人数据。
5. **历史预测需要审计预处理。** 原预处理会利用全段最低高度，边界速度使用下一帧。历史实验单独处理这两项，同时明确未来接触类型/窗口是外部给定目标；不能称自主战术规划。

## 下一步的科学门槛

2026-09-15补充：第七步首轮组件实验9/9完成，36条评估记录及9个不同模型校验通过，38个单元测试通过。新增训练共98,304,000环境步，另复用1次同预算模型。详见 `records/step7/summary.json`、`records/step7/artifact_check.json` 与 `docs/step7_protocol.md`。训练组与生成参考数量不同，因此同总预算不代表同真实来源交互量；误差只在首次失配前统计，不能单凭较小误差宣称改善。

当前首要问题是让相同多参考控制器覆盖真实与生成动作，并验证显式时序交互条件。只有相对跟踪、双方空间关系和接触观测都可靠后，物理critic和数据效用实验才具有可解释性。

如果训练源动作本身仍频繁失配，不能把“生成组也失败”解释成生成动作必然不可执行。反之，人体几何接触成功也不能跳过机器人验证。所有暂未达标项如实保留，不以视频或单个成功片段替代。
