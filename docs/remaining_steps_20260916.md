## 无GPU复核

在仓库根目录执行：

```bash
python -m scripts.verify_bm1_archive
python -m unittest tests.test_benchmark_conditions tests.test_benchmark_results tests.test_benchmark_readiness -v
python -m scripts.check_benchmark_readiness --output records/readiness_new.json
```

最后一个命令在空模板上预期返回2；只有填入真实输入并通过一致性检查才可能返回0。0仍只表示来源格式一致，不自动证明标注准确、统计充分或机器人可执行。
